# Агент пошуку трансляцій (stream-search)

**Призначення.** Вночі шукає відкриті сторінки мовників, організаторів і їхні офіційні анонси, де є посилання на трансляції YouTube, і **лише пропонує** серверу відео чи канали. Нічого не погоджує, не публікує й не змінює: рішення — за власником у слайсі «Джерела» адмінки (SPEC-21a).

**Одна команда запуску** (з теки `web/`, однакова на ПК власника й на сервері, Windows і Linux):

```
node server/scripts/stream-agent.mjs run
```

Команда запускає `claude -p` з файлом `agents/stream-search/prompt.md` і списком дозволених інструментів: лише команди цього клієнта (`channels`, `candidates`, `propose`) і читання відкритих вебсторінок.

**Змінні середовища** (лише назви; значення — у власника, ніколи в репозиторії, промпті чи виводі):

- `T2F_STREAM_AGENT_BASE_URL`
- `T2F_STREAM_AGENT_KEY`
- `T2F_STREAM_AGENT_ACCESS_CLIENT_ID`
- `T2F_STREAM_AGENT_ACCESS_CLIENT_SECRET`

Без однієї з них клієнт завершується з кодом 2 і називає відсутню змінну.

**Межі одного прогону:** ≤ 60 хвилин і ≤ 50 пропозицій. Ключ ролі `stream-agent` на сервері має власні ліміти (30 запитів на хвилину, добова стеля); відповідь 429 або 403 — зупинка прогону.

**Заборонено:** скрейпінг і браузерний пошук на youtube.com; погодження, відхилення, зміна каналів, чорний список; будь-яка адреса, крім трьох адрес клієнта.

**Ізоляція запуску (S21-01, S21-05):** сесія працює в порожній тимчасовій теці поза репозиторієм; промпт іде через stdin; доступні лише інструменти Bash (тільки три команди клієнта) і WebFetch; без MCP-серверів і без налаштувань користувача чи проєкту (`--setting-sources ""`, `--strict-mcp-config`). Заборону youtube.com і локальних адрес забезпечують правила `--disallowedTools WebFetch(domain:…)`, а не лише промпт. Клієнт відмовляє (код 2), якщо аргумент містить значення будь-якої секретної змінної.

**Розклад:** `schedule.md`. **Промпт:** `prompt.md`.
